# 📚 StudyBuddyBot — Интерактивный учебник алгоритмов в Telegram

**Превратите изучение алгоритмов из скучной теории в живой эксперимент.**

Пользователь не просто читает, а **вводит свои данные** и смотрит, как сортировка или поиск работают в реальном времени. С гифками, пошаговым объяснением и без установки IDE.

👇 **Попробовать бота:** [@StudyBuddy_algorithm_bot](ССЫЛКА_НА_БОТА)  
📦 **Исходный код:** [GitHub](https://github.com/Mateush2131/Studybudybotdeploy)

## ✨ Функции, которые делают бота уникальным

✅ **15+ алгоритмов** — от пузырька до Дейкстры и задачи о рюкзаке  
✅ **4 категории** — сортировки, поиск, графы, динамическое программирование  
✅ **Интерактивные демо** — введи `[5, 2, 8, 1]` и смотри, как сортировка вставками раскладывает их по шагам  
✅ **Визуализации GIF** — наглядное объяснение сложных концепций  
✅ **Мгновенный доступ** — не нужно качать IDE, всё работает прямо в Telegram  
✅ **Русский язык** — понятная терминология и интерфейс

## 🧠 Как работает интерактив (это главная фича!)

1. Пользователь выбирает **"Интерактив: Сортировка пузырьком"**
2. Бот просит ввести числа через запятую (например: `4, 2, 7, 1`)
3. Бот **пошагово** показывает:

4. 4. Пользователь **видит логику своими глазами** и запоминает навсегда.

Такого нет в 90% учебных ботов.
