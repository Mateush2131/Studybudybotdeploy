# 🤖 StudyBuddy Bot — Telegram-помощник для учёбы

Интерактивный бот для управления расписанием, дедлайнами и заметками. Помогает студентам и школьникам организовать учебный процесс прямо в Telegram.

---

## 🎯 Функционал

| Функция | Описание |
|---------|----------|
| 📅 **Расписание** | Добавление пар/занятий с указанием дня, времени и предмета |
| ⏰ **Дедлайны** | Управление сроками сдачи заданий с датами |
| 📝 **Заметки** | Быстрое сохранение текстовых заметок |
| 🔍 **Поиск** | Поиск по сохранённым заметкам |
| 📋 **Сегодня** | Просмотр расписания на текущий день |
| 💾 **Быстрые заметки** | Любое сообщение боту сохраняется как заметка |
| 🌅 **Утренние напоминания** | Ежедневные уведомления в 8:00 по МСК |

---

## 🛠️ Технологии

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.11+ |
| Фреймворк | aiogram 3.x |
| Хранение данных | JSON (локально) |
| Планировщик | APScheduler |
| Веб-сервер | aiohttp (health-check) |
| Деплой | Render / VPS |
